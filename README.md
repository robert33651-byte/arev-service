# Arev Service: контроль выездных сотрудников

Здесь три части:

| Папка | Что это | Где работает |
|---|---|---|
| `mobile/` | Приложение сотрудника для Android | Телефоны сотрудников |
| `admin/` | Админка для руководителя | Браузер на ПК |
| `supabase/` | База данных, правила доступа, серверная функция | Ваш проект Supabase |

Всё делается через сайты, ничего не нужно устанавливать на компьютер.

---

## Шаг 1. Сервер Supabase (15 минут)

1. Зайдите на **supabase.com** → **New project**.
   * Name: `arev-service`
   * Region: **Central EU (Frankfurt)**
   * Database password: придумайте и сохраните у себя. Никому не отправляйте.
2. Дождитесь, пока проект создастся (1–2 минуты).
3. Слева **SQL Editor** → **New query**. Откройте файл `supabase/schema.sql`, скопируйте его целиком, вставьте и нажмите **Run**. Внизу должно появиться «Success».
4. Слева **Authentication** → **Sign In / Providers** → **Email**:
   * выключите **Confirm email** (сотрудники входят по телефону и PIN-коду, писем не получают);
   * нажмите **Save**.
5. Слева **Project Settings** → **API**. Вам понадобятся два значения:
   * **Project URL** (вида `https://abcd.supabase.co`);
   * ключ **anon public**.
   Их можно прислать Claude, они не секретные. Ключ **service_role** никому не отправляйте.

## Шаг 2. ИИ-проверка фото (10 минут, можно позже)

1. Зайдите на **console.anthropic.com**, зарегистрируйтесь, пополните баланс (хватит $5–10 на месяцы проверок).
2. **API Keys** → **Create Key** → скопируйте ключ.
3. В Supabase слева **Edge Functions** → **Secrets** → **Add new secret**:
   * Name: `ANTHROPIC_API_KEY`
   * Value: ваш ключ → **Save**.
4. **Edge Functions** → **Deploy a new function** → **Via Editor**:
   * имя функции: `admin-tools`
   * удалите пример кода, вставьте весь файл `supabase/functions/admin-tools/index.ts`
   * **Deploy**.

## Шаг 3. Админка на ПК (10 минут)

1. В файле `admin/config.js` вставьте Project URL и ключ anon public (Claude может сделать это за вас).
2. Зайдите на **vercel.com** → войдите через GitHub → **Add New** → **Project** → выберите репозиторий `arev-service` → **Import**.
3. **Root Directory**: нажмите **Edit** и выберите папку `admin`. Framework Preset: **Other**. Нажмите **Deploy**.
4. Через минуту появится адрес вида `arev-service.vercel.app`. Это ваша админка. Добавьте её в закладки.
5. Первый вход: откройте адрес → **Создать аккаунт администратора** (ваш e-mail и пароль от 8 символов) → **Войти** → **Стать администратором**. Кнопка срабатывает только для первого человека.
6. В админке: **Настройки** → координаты офиса, имя офисного Wi-Fi, рабочее время → **Сохранить**.

## Шаг 4. Приложение для телефонов (20 минут на первую сборку)

1. В файле `mobile/src/config.js` вставьте Project URL и ключ anon public (Claude может сделать это за вас).
2. Зайдите на **expo.dev** → **Create a project** → имя `arev-service-master`. Скопируйте **Project ID** и вставьте его в `mobile/app.json` вместо `ВСТАВЬТЕ_ID_ПРОЕКТА_EXPO` (или пришлите Claude).
3. В проекте на expo.dev: **Project settings** → **GitHub** → подключите репозиторий `arev-service`, в поле **Base directory** укажите `mobile`.
4. **Builds** → **Build from GitHub** (или **New build**) → Platform: **Android**, Profile: **preview** → **Build**.
5. Через 10–20 минут появится кнопка **Install** и QR-код. Это файл APK.

## Шаг 5. Установка на телефон сотрудника

1. Откройте ссылку на сборку (или QR-код) на телефоне сотрудника → скачайте APK.
2. Android спросит про установку из неизвестного источника: разрешите для браузера.
3. Откройте **Arev Service** → **Я новый сотрудник** → телефон и PIN-код из 6 цифр → анкета.
4. При запросах разрешений выберите **Камера: разрешить** и **Местоположение: разрешить всегда**.
5. В админке: **Сотрудники** → **Принять**. Сразу укажите последние 4 цифры его топливной карты.

Готово: сотрудник может начинать смену.

## Как обновлять приложение

Когда Claude вносит изменения, повторите в expo.dev **Build from GitHub** и отправьте сотрудникам новую ссылку. Позже, при переходе на Google Play, обновления будут приходить сами.

## Если что-то не работает

Сделайте скриншот ошибки (в expo.dev: страница сборки → **Logs**; в Supabase: красное сообщение) и пришлите Claude.

## Что защищено

* Все действия сотрудника идут через серверные функции. Время ставит сервер, телефон изменить его не может.
* Сотрудник не может изменить или удалить уже записанные смены, заправки и фото.
* Сотрудник видит только свои данные. Чужие смены, выписку по картам и тревоги видит только админ.
* Отметка с подменой GPS отклоняется, а админ получает тревогу.
* Отметка с другого телефона отклоняется. Сменить телефон можно только с разрешения админа.
* Фото делаются только камерой приложения, галереи нет. Сервер принимает фото не старше 10 минут.
* Приход и уход проверяются по координатам и офисному Wi-Fi.
* Маршрут смены записывается в фоне. Невозможные перемещения подсвечиваются.
* Литры сверяются с выпиской по топливной карте, цифры на фото проверяет ИИ.
